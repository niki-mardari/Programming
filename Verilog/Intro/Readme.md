# Verilog 
- It is a Hardware Description Language (HDL). It will make the hardware that will run c/ c++ code. 
- It is a hardware description language. It is used to model electronic systems.
- There must be concurrency, Verilog is a parallel programming language. 

# Steps of designing a circuit using Verilog:
1. Write the code in Verilog.
2. Compiling the code to produce a circuit. (Logic Synthesis)
3. Simulating the circuit to check if it is working as expected/ fixing bugs.
